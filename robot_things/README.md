# 机器人算法学习项目

从零开始学习机器人相关算法，循序渐进。

## 学习路线

| 课程 | 主题 | 文件 | 核心知识点 |
|------|------|------|-----------|
| 01 | 坐标变换与运动学 | `01_kinematics/` | 齐次变换矩阵、正运动学、逆运动学 |
| 02 | 路径规划 | `02_path_planning/` | A*算法、RRT算法、势场法 |
| 03 | 感知与定位 | `03_perception/` | 卡尔曼滤波、粒子滤波、SLAM基础 |
| 04 | 运动控制 | `04_control/` | PID控制、轨迹跟踪 |
| 05 | 综合项目 | `05_project/` | 移动机器人仿真 |

## 环境准备

```bash
pip install numpy matplotlib
```

## 如何学习

每个课程文件夹内：
- `lesson_xx.py` — 带详细注释的教学代码，可直接运行看效果
- 每个文件顶部有该课的知识点说明
- 代码中穿插了练习题，鼓励动手修改参数观察变化
