## 测试 1: 单事件分析 ✅

### 输入
```json
{
    "event_id": "test_fire_001",
    "event_type": "突发事件",
    "event_description": "某地发生火灾，多名网友发布现场视频",
    "related_content": [
        "@消防员小王 发布了现场救援视频",
        "@新闻记者李明 报道了事件经过",
        "user_12345 转发并评论：希望大家平安",
        "#火灾救援 话题下有大量讨论"
    ]
}
```

### 处理结果

#### 1. 实体抽取
- ✅ 账号: 3 个
  - 新闻记者李明
  - 消防员小王
  - 12345
- ✅ 关键词: 5 个
  - 火灾、救援、消防、新闻、报道
- ✅ 话题: 1 个
  - #火灾救援

#### 2. 身份识别
| 账号 | 识别身份 | 准确性 |
|------|---------|--------|
| 消防员小王 | 消防员 | ✅ 正确 |
| 新闻记者李明 | 记者 | ✅ 正确 |
| 12345 | 未知身份 | ✅ 合理 |

#### 3. 角色分析
| 账号 | 事件角色 | 风险等级 |
|------|---------|---------|
| 消防员小王 | 信息发布者 | 低 |
| 新闻记者李明 | 信息发布者 | 低 |
| 12345 | 信息发布者 | 低 |

#### 4. 输出文件
- ✅ `test_event_analysis_test_fire_001.json` - 完整分析报告
- ✅ `test_profiles.db` - 画像数据库
